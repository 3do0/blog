# فضاء التقنية.. - مدونة تقنية عربية

فضاء التقنية.. مدونة تقنية باللغة العربية بتصميم احترافي وتجربة مستخدم مميزة. مبنية بـ HTML, CSS, و JavaScript الصافي بدون استخدام أي أطر خارجية.

## نظرة عامة

فضاء التقنية.. هي منصة تفاعلية لمشاركة أحدث المقالات والأفكار في عالم التكنولوجيا والتطوير مع تجربة مستخدم مميزة، تصميم جذاب، وأداء سريع.

### المميزات الرئيسية

- تصميم عصري وجذاب متوافق مع جميع الأجهزة
- واجهة مستخدم سهلة الاستخدام (UI/UX)
- دعم كامل للغة العربية (RTL)
- تأثيرات بصرية متقدمة (Animations & Transitions)
- نظام تسجيل دخول وإنشاء حساب
- نموذج اتصال تفاعلي مع التحقق من البيانات
- معرض مقالات تفاعلي مع نظام بحث
- قسم carousel للمقالات المميزة
- شريط تنقل متجاوب مع قائمة hamburger للشاشات الصغيرة
- إمكانية الوصول (Accessibility) محسّنة
- SEO محسّن

## التقنيات المستخدمة

- **HTML5** - هيكل الصفحات مع عناصر دلالية (Semantic HTML)
- **CSS3** - التصميم والتنسيق مع تأثيرات متقدمة
  - Flexbox & Grid للتخطيط
  - CSS Variables للألوان والقيم المشتركة
  - CSS Animations & Transitions
  - Glassmorphism Effects
- **JavaScript (ES6+)** - التفاعلية والوظائف

  # فِضَاء التِقْنِيَّة — مشروع مدونة ثابتة (Static Blog)

  محتوى هذا المستودع هو موقع مدونة ثابت (HTML/CSS/JS) مكتوب بالعربية (اتجاه يمين لليسار). README السابق احتوى معلومات عامة وغير دقيقة، فقمت بإعادة صياغته ليطابق الملفات الموجودة فعلاً في المشروع.

  ## لمحة سريعة

  - مشروع بسيط مُصمم بالـ HTML، CSS، وJavaScript بدون سيرفر من جانب الخادم.
  - الواجهة باللغة العربية (lang="ar" dir="rtl").
  - المحتوى (المقالات) مخزن مؤقتاً داخل ملف `js/script.js` كمصفوفة `DB.posts` (mock data).
  - لا توجد قاعدة بيانات خارجية أو إعدادات back-end.

  ## بنية المشروع (الملفات المهمة)

  - `index.html` — الصفحة الرئيسية: هيرو، سلايدر (Swiper) وأحدث المقالات.
  - `posts.html` — صفحة عرض المقالات / أرشيف.
  - `article.html` — قالب عرض مقال واحد؛ يقبل باراميتر `?slug=...` لعرض المقال.
  - `about.html`, `contact.html`, `signin.html`, `signup.html` — صفحات معلومات ونماذج بسيطة.
  - `css/styles.css` — ملف الأنماط الرئيسي.
  - `js/script.js` — المنطق الأمامي: تحميل المقالات من `DB.posts`, تهيئة التنقل، السلايدر، والنماذج.
  - `assets/` — صور وخطوط ومصادر ثابتة.

  ## ملاحظات حول التبعيات

  المشروع يعتمد على بعض موارد CDN (غير مضمنة محلياً):

  - Swiper.js (carousel): https://cdn.jsdelivr.net/npm/swiper@11/swiper-bundle.min.css و `.js` (مستدعى في `index.html`).
  - Font Awesome لأيقونات: مستدعى عبر CDN في ملفات HTML.

  لا يوجد `package.json` أو نظام إدارة تبعيات محلي (npm/pnpm). هذه نسخة بسيطة تعمل مباشرة من الملفات المحلية.

  ## كيف تشغل المشروع محلياً

  الطريقة الأسهل: افتح `index.html` أو أي صفحة HTML في المتصفح مباشرة. بعض ميزات التاريخ/الملاحة تعمل أيضاً دون إعداد.


  ## كيفية تعديل المقالات

  المقالات حالياً مخزنة كمجموعة كائنات في `js/script.js` داخل المتغير `DB.posts`.

  كل عنصر مقال يحتوي على الحقول التالية (موجز):

  - id (رقم)
  - title (نص)
  - slug (نص فريد يُستخدم في رابط `article.html?slug=...`)
  - excerpt (مقتطف)
  - content (HTML صالح يُعرض داخل صفحة المقال)
  - image (مسار الصورة)
  - category (اسم التصنيف)
  - tags (مصفوفة نصية)
  - published_at (تاريخ بصيغة YYYY-MM-DD)

  لتعديل/إضافة مقال: افتح `js/script.js` وحرّر/أضف كائن داخل الـ `DB.posts`. احفظ ثم أعد تحميل الصفحة.

  ## أمور يمكن تحسينها لاحقاً (اقتراحات)

  - نقل المحتوى إلى ملفات Markdown أو JSON منفصلة وتحميلها ديناميكياً.
  - إضافة إعداد بناء (مثل `npm` + `parcel`/`vite`) لتجميع الموارد.
  - استبدال CDN بخيارات محلية أو إضافة fallbacks عند انقطاع CDN.
  - تحسين النماذج لإرسال بيانات فعلية إلى back-end.
  - إضافة فحوصات وصولية (lighthouse/accessibility checks).

  - إذا تريد، أستطيع: تحديث README بصيغة أقصر/أطول، إضافة مثال سريع لكتابة مقال جديد، أو تحويل المقالات إلى ملفات JSON/Markdown وتنفيذ تحميلها.
