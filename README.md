# مدونة عصرية - Modern Arabic Blog

مدونة تقنية عصرية باللغة العربية بتصميم احترافي وتجربة مستخدم استثنائية. مبنية بـ HTML, CSS, و JavaScript الصافي بدون استخدام أي أطر خارجية.

## نظرة عامة

مدونة عصرية هي منصة تفاعلية لمشاركة أحدث المقالات والأفكار في عالم التكنولوجيا والتطوير مع تجربة مستخدم مميزة، تصميم جذاب، وأداء سريع.

### المميزات الرئيسية

- تصميم عصري وجذاب متوافق مع جميع الأجهزة
- واجهة مستخدم سهلة الاستخدام (UI/UX)
- دعم كامل للغة العربية (RTL)
- تأثيرات بصرية متقدمة (Animations & Transitions)
- نظام تسجيل دخول وإنشاء حساب
- نموذج اتصال تفاعلي مع التحقق من البيانات
- معرض مقالات تفاعلي مع نظام بحث
- قسم carousel للمقالات المميزة
- شريط تنقل متجاوب مع قائمة hamburger للشاشات الصغيرة
- إمكانية الوصول (Accessibility) محسّنة
- SEO محسّن

## الصفحات المتاحة

| الصفحة       | الوصف                               | المسار         |
| ------------ | ----------------------------------- | -------------- |
| الرئيسية     | الصفحة الرئيسية مع المقالات المميزة | `index.html`   |

## التقنيات المستخدمة

- **HTML5** - هيكل الصفحات مع عناصر دلالية (Semantic HTML)
- **CSS3** - التصميم والتنسيق مع تأثيرات متقدمة
  - Flexbox & Grid للتخطيط
  - CSS Variables للألوان والقيم المشتركة
  - CSS Animations & Transitions
  - Glassmorphism Effects
- **JavaScript (ES6+)** - التفاعلية والوظائف
  - Form Validation
  - DOM Manipulation
  - Event Handling
  - Local Storage (للبيانات المحلية)
- **Font Awesome** - الأيقونات
- **Google Fonts (Tajawal)** - الخطوط العربية

## الوظائف الرئيسية

### 1. نظام التسجيل والدخول

- نموذج تسجيل دخول مع التحقق من البريد الإلكتروني وكلمة المرور
- نموذج إنشاء حساب جديد مع:
  - التحقق من قوة كلمة المرور
  - تأكيد كلمة المرور
  - الموافقة على الشروط والأحكام
- إظهار/إخفاء كلمة المرور
- رسائل خطأ ونجاح واضحة ومرئية

### 2. نموذج الاتصال

- حقول: الاسم، البريد الإلكتروني، الموضوع، الرسالة
- التحقق من صحة البيانات قبل الإرسال (Client-side validation)
- رسائل خطأ مخصصة لكل حقل
- رسالة نجاح عند الإرسال

### 3. شريط التنقل

- تصميم متجاوب (Responsive)
- قائمة hamburger للشاشات الصغيرة
- تأثيرات hover جذابة
- دعم التنقل بلوحة المفاتيح (Keyboard Navigation)

### 4. البحث

- نافذة بحث منبثقة (Modal)
- بحث في المقالات بالعنوان والوصف والكلمات المفتاحية
- عرض النتائج فوري

### 5. عرض carousel للمقالات

- تلقائي مع إمكانية التحكم اليدوي
- نقاط التنقل (Dots)
- أزرار السابق والتالي
- توقف عند الـ hover
- دعم لوحة المفاتيح (مفاتيح الأسهم)

## ملاحظات مهمة

### التحقق من النماذج (Form Validation)

التحقق يتم على مستوى المتصفح (Client-side) فقط:

- **البريد الإلكتروني**: تنسيق صحيح (example@domain.com)
- **كلمة المرور**: 8 أحرف على الأقل
- **الاسم**: 3 أحرف على الأقل
- **الرسالة**: 10 أحرف على الأقل

### الصور

تستخدم المدونة صور من Pexels (خدمة صور مجانية). الروابط موجودة مباشرة في الكود. يمكنك استبدالها بصور محلية إذا أردت.

### البيانات

المقالات مخزنة حالياً في ملف JavaScript كـ mock data. في بيئة الإنتاج، يمكن ربطها بقاعدة بيانات أو API.
